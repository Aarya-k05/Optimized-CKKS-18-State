9. INTERPRETATION
The controller computes the state-feedback dot product using
a CKKS ciphertext and a plaintext gain vector. Only the resulting
control signal is decrypted before it is applied to the simulated
plant. The plaintext controller is retained as a baseline so the
effect of CKKS approximation can be quantified. Note that the
HE pipeline itself (encrypt -> homomorphic dot product -> decrypt)
is unchanged from the 2-state version: TenSEAL's dot() already
handles a 18-element vector the same way it handled a 2-element one.
